# SP letter template (draft for approval)

The Hub fills this in when a sanction is issued (ADR-0001, grill G-38, G-44) and saves it as
a Google Doc in **Company > HR > Surat Peringatan**, one file per letter, named
`{nomor} - {nama} - {jenis_surat}`. `{…}` are filled by the Hub. Blocks marked
*[only when …]* appear only in that case. Point values follow the Hub's convention: Violation
negative, Excellence positive (G-45).

One template covers four letters: **SP1**, **SP2**, **SP3**, and the **Peringatan Pertama dan
Terakhir** of §4.3.2 (equal to SP3). A teguran lisan gets no letter. Termination is never
written by the Hub.

  (Yogyakarta) are both on the letterhead.
- **Letter number** (`{nomor}`): `{urut}/SP/ESK/{bulan romawi}/{tahun}`, e.g.
  `003/SP/ESK/X/2026`, counting from 001 each year.

  Hub's people list (the Owner, and the person holding Brand Manager in Eskala).
